# MoMoSDK v0.1.0

Initial experimental source release under the [MIT license](https://github.com/KAbaidoo/momo-swift/blob/v0.1.0/LICENSE). APIs may change between pre-1.0 minor versions; maintenance is best-effort without a production support commitment.

## Products and requirements

Swift Package Manager products: `MoMoSDK`, `MoMoCore`, `MoMoCollections`, `MoMoDisbursements`, and `MoMoRemittance`. The SDK includes consumer consent and sandbox provisioning clients.

Requires Swift 6.2+. Declared platforms are iOS 16, macOS 13, watchOS 8, tvOS 15, and Linux. Policy-based wait APIs support those floors; legacy `Duration` wait overloads require watchOS 9/tvOS 16.

## Installation and setup

Add `https://github.com/KAbaidoo/momo-swift.git` in Xcode and select `0.1.0`, or use:

```swift
.package(url: "https://github.com/KAbaidoo/momo-swift.git", exact: "0.1.0")
// Target dependency:
.product(name: "MoMoSDK", package: "momo-swift")
```

See the versioned [README](https://github.com/KAbaidoo/momo-swift/blob/v0.1.0/README.md) for product credentials, safe submission/reconciliation, and demo setup. Read the [migration notes](https://github.com/KAbaidoo/momo-swift/blob/v0.1.0/docs/MIGRATION.md) before updating existing clients, including the explicit pre-submission failure classification. Keep merchant credentials on a trusted backend. No binary distribution is included.

## Verification and limits

Publication requires Apple and Linux verification of the exact tagged commit: root tests, nested SDK tests on Apple, external consumer build, Apple deployment floors, and iOS Simulator demo build. The publisher additionally resolves and builds a separate Swift package through this exact version tag and confirms its resolved commit. The verified SHA is appended to these notes by the pipeline.

These checks establish offline contract behavior and build compatibility. They do not certify production interoperability, operator entitlements, fees, settlement, or callback delivery. Operator evidence and explicit exclusions are recorded in the versioned [release-readiness record](https://github.com/KAbaidoo/momo-swift/blob/v0.1.0/docs/RELEASE_READINESS.md).

Voucher methods remain deprecated/unverified; suspicious cloned Remittance routes and narrative-only consent financial operations are excluded. Optional aggregator `transferType` values and eligibility require operator confirmation. See [API coverage](https://github.com/KAbaidoo/momo-swift/blob/v0.1.0/docs/API_COVERAGE.md) for contract discrepancies and boundaries. A compiled demo is not evidence of a completed live transaction.
